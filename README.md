# Hisopi

**Gerenciamento inteligente de alimentos e controle de estoque para reduzir o desperdício.**

Introdução

O Hisopi é uma solução multiplataforma desenvolvida com o objetivo de auxiliar no gerenciamento de alimentos e no controle de estoque, contribuindo para a redução do desperdício alimentar em ambientes domésticos e comerciais.
A plataforma permite registrar, organizar e acompanhar produtos, considerando suas datas de validade para orientar o consumo e a utilização dos alimentos de maneira mais eficiente.
O sistema utiliza o conceito **FEFO (First Expired, First Out)**, priorizando a utilização dos alimentos com vencimento mais próximo.

## Problema e proposta

O desperdício alimentar está frequentemente associado à falta de controle sobre os alimentos armazenados, ao esquecimento de datas de validade e à gestão inadequada de estoques.
O Hisopi propõe centralizar essas informações em uma única plataforma, oferecendo ferramentas para facilitar o acompanhamento dos alimentos e auxiliar na tomada de decisões.
